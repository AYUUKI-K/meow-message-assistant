# 喵喵消息助手

一个用于 SillyTavern「酒馆助手」脚本库的消息阅读工具。点开悬浮猫猫，就能跳楼、查历史回复、搜索和收藏消息，也可以开启自动阅读。

[下载在线更新版 JSON](https://raw.githubusercontent.com/AYUUKI-K/meow-message-assistant/release/meow-assistant.json) · [下载离线版 JSON](https://raw.githubusercontent.com/AYUUKI-K/meow-message-assistant/release/meow-offline.json) · [更新日志](CHANGELOG.md)

## 能做什么

- **楼层导航**：回到当前楼层顶部或底部，输入楼层号跳转，返回跳转前的阅读位置。
- **历史阅读**：在轻量窗口查看历史消息和 Swipe，不用把中间所有楼层加载到聊天页面，也不会切换聊天中选中的 Swipe。
- **全楼层搜索**：按楼层号精确查找，或搜索当前聊天的角色名与正文关键词，点击结果即可阅读。
- **消息收藏**：收藏楼层、添加备注标题，在收藏夹搜索和跳转。顺序阅读默认跳过收藏楼层，可在显示设置中关闭。
- **阅读选项**：勾选隐藏用户输入楼层，或在回复输出完成后自动回到该楼顶部。
- **自动阅读**：四档滚动速度，历史阅读窗口可勾选“读完续楼”。
- **主题与手机适配**：面板和猫猫跟随酒馆当前 CSS 主题配色；电脑端使用小面板和居中阅读窗口，手机端提供全屏操作与侧边收纳。

## 安装

1. 下载安装链接中的 JSON 文件。
2. 打开酒馆助手的**脚本库**，导入并启用脚本。
3. 更新已有版本时覆盖原脚本。请停用旧版助手和独立 Swipe 查看脚本，避免出现重复控件。

在线版与离线版使用同一个脚本 ID，选择其中一个使用即可。

## 怎么用

**点猫猫打开面板。** 悬浮按钮上的上、下键用于回到当前楼层顶部或底部。楼层号从 `0` 开始；远距离跳转会通过轻量阅读窗口打开目标消息，点“返回聊天”回到原位置。

**手机侧边收纳。** 轻点边缘短线展开上下按钮，点页面其他位置收回。长按边缘条后上下拖动，猫猫也可以直接上下拖动。

**隐藏输入与输出后回顶。** 在主面板勾选“隐藏用户输入楼层”或“输出完成后回到本楼顶部”，也可在阅读器的“显示设置”中调整。两项默认关闭，刷新后保留勾选状态。隐藏仅影响显示，原消息、楼层编号和发送给模型的聊天内容都会保留。

**自动阅读。** 在主面板或阅读窗口点“自动阅读”，选择慢速、舒适、较快或快速。触屏、滚轮或切到后台会暂停；聊天页面下方也有暂停入口。只记住速度，下次打开不会自行播放。“读完续楼”默认关闭，仅在历史阅读窗口生效。

**正文与美化。** 历史阅读支持酒馆显示正则、Markdown 和 HTML/CSS；HTML 文档在独立 iframe 中运行，保留自身样式与内部交互。可在“显示设置”中启用“仅正文”，并填写正文的起止标签。

## 更新与数据保存

- **在线版**：刷新酒馆或重新启用脚本时获取最新发布；正在阅读时不会轮询更新或强制重启。
- **离线版**：保持已导入的版本，需要更新时手动下载并导入新版 JSON。
- **收藏与备注**：按角色/群组和聊天分别保存在当前浏览器本地。阅读选项、速度和悬浮位置也保存在本地，不会自动同步到其他浏览器或设备。

版本变化见 [更新日志](CHANGELOG.md)。

## 开发与共创

源码保存在 `main` 分支，使用拆分的 TypeScript 和 CSS 维护。`release` 分支存放在线更新需要的发布文件。

<details>
<summary>构建与源码说明</summary>

首次安装依赖，随后构建：

```sh
npm ci
npm run build
```

构建入口是 `index.ts`，CSS 会内嵌到脚本中；在线加载器导出为源码目录上一级的 `喵喵消息助手-酒馆助手导入.json`。

| 源码 | 用途 |
| --- | --- |
| `assistant.ts`、`ui.ts`、`assistant.css` | 消息操作、界面结构与样式 |
| `reading-preferences.ts`、`generation-return.ts`、`floor-search.ts` | 阅读选项、输出后回顶与楼层搜索 |
| `message-access.ts`、`message-renderer.ts`、`html-document.ts`、`archive.ts` | 消息读取、美化渲染与目录 |
| `auto-reader.ts`、`dock-drag.ts`、`positioning.ts` | 自动阅读、拖拽与定位 |
| `cat-icons.ts`、`native-theme.ts` | 猫猫图标与酒馆主题取色 |
| `online-loader.ts`、`script-metadata.ts`、`version.ts` | 在线加载、脚本信息与运行版本号 |
| `build.mjs`、`.github/workflows/publish.yml` | 打包与自动发布 |

向 `main` 推送运行源码或构建配置的变更后，GitHub Actions 会自动构建，成功后发布到 `release`。完整脚本使用内容指纹文件名；在线加载器读取发布清单后加载对应脚本。

</details>
